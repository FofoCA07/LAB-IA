# Plantillas de LAB-IA

Versión: 1.0

---

# Objetivo

Este documento define las plantillas base utilizadas por LAB-IA para iniciar proyectos de forma consistente.

Las plantillas representan estructuras recomendadas, no reglas obligatorias.

Siempre podrán adaptarse según las necesidades del proyecto.

---

# Proyecto General

Debe incluir como mínimo:

- README.md
- .gitignore
- Estructura organizada
- Documentación básica

---

# Proyecto Java

Recomendado para:

- Maven
- Spring Boot
- OpenXava

Debe incluir:

- src
- resources
- README
- pom.xml

---

# Proyecto C#

Recomendado para:

- .NET
- ASP.NET
- Consola
- Windows Forms

Debe incluir:

- Solution
- Proyecto principal
- README

---

# Base de Datos

Debe incluir:

- Modelo
- Scripts
- Documentación

---

# Docker

Cuando un proyecto utilice Docker, se recomienda incluir:

- Dockerfile
- docker-compose.yml
- .dockerignore

---

# README

Todo proyecto debe explicar:

- Objetivo
- Tecnologías
- Instalación
- Uso

---

# Git

Siempre que sea posible:

- Inicializar repositorio
- Crear primer commit
- Mantener historial limpio

---

# Regla General

Las plantillas sirven como punto de partida.

Nunca deben impedir adaptar la estructura a las necesidades reales del proyecto.
