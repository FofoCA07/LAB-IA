# Roadmap de LAB-IA

Versión actual: 1.0

---

# Objetivo

Este documento describe la evolución planificada del laboratorio.

El Roadmap sirve como guía para mantener una dirección clara durante el desarrollo de LAB-IA.

Las versiones pueden cambiar con el tiempo según las necesidades del proyecto.

---

# Versión 1.0

Estado: Completada

Incluye:

- Infraestructura inicial
- Docker
- Ollama
- OpenCode
- Agentes personalizados
- Documentación base

---

# Versión 1.1

Estado: En planificación

Objetivos:

- Mejorar los agentes existentes.
- Refinar Prompt Engineer.
- Optimizar los flujos de trabajo.
- Mejorar la documentación.

---

# Versión 1.2

Estado: Pendiente

Objetivos:

- Integración con Visual Studio Code.
- Integración con IntelliJ IDEA.
- Integración con Visual Studio.

---

# Versión 2.0

Estado: Pendiente

Objetivos:

- Automatización de tareas.
- Mejor colaboración entre agentes.
- Plantillas inteligentes.
- Mejor experiencia de desarrollo.

---

# Futuro

A largo plazo LAB-IA buscará convertirse en un entorno personal de desarrollo asistido por inteligencia artificial.

Cada nueva versión deberá mejorar la experiencia sin perder la filosofía principal del laboratorio:

Simplicidad.

Claridad.

Organización.

Aprendizaje continuo.
