# Protocolos de LAB-IA

Versión: 1.0

---

# Introducción

Los protocolos definen la forma recomendada de trabajar dentro de LAB-IA.

Un protocolo indica qué agentes utilizar, en qué orden y cuál es el objetivo del proceso.

Seguir un protocolo ayuda a mantener un flujo de trabajo consistente y organizado.

---

# Protocolo 1 - Nuevo Proyecto

## Objetivo

Iniciar un proyecto desde cero de forma organizada.

## Agentes

- Senior Developer
- Reviewer

## Flujo

1. Crear la carpeta del proyecto.
2. Inicializar Git (si aplica).
3. Analizar los requisitos.
4. Diseñar la estructura inicial.
5. Implementar la base del proyecto.
6. Revisar la estructura antes de comenzar el desarrollo.

## Resultado esperado

Proyecto listo para empezar a desarrollar.

---

# Protocolo 2 - Proyecto Existente

## Objetivo

Comprender un proyecto antes de modificarlo.

## Agentes

- Senior Developer
- Reviewer

## Flujo

1. Analizar la estructura del proyecto.
2. Identificar la tecnología utilizada.
3. Comprender la arquitectura.
4. Detectar posibles riesgos.
5. Comenzar únicamente cuando exista suficiente contexto.

---

# Protocolo 3 - Bug o Error

## Objetivo

Resolver un problema correctamente.

## Agentes

- Debugger
- Reviewer
- Senior Developer

## Flujo

1. Reproducir el problema.
2. Leer el mensaje de error completo.
3. Buscar la causa raíz.
4. Aplicar la corrección.
5. Revisar que no existan efectos secundarios.

---

# Protocolo 4 - Revisión de Código

## Objetivo

Verificar la calidad del proyecto.

## Agente

- Reviewer

## Flujo

1. Analizar el código.
2. Detectar problemas.
3. Clasificar su importancia.
4. Proponer mejoras.
5. Aplicarlas solo si el usuario lo solicita.

---

# Protocolo 5 - Aprendizaje

## Objetivo

Aprender una tecnología o resolver dudas.

## Agentes

- Profesor
- Senior Developer (opcional)

## Flujo

1. Comprender el tema.
2. Resolver ejemplos sencillos.
3. Practicar.
4. Aplicar el conocimiento en un proyecto.

---

# Protocolo 6 - Bases de Datos

## Objetivo

Diseñar u optimizar bases de datos.

## Agentes

- SQL Expert
- Reviewer

## Flujo

1. Analizar el modelo.
2. Revisar relaciones.
3. Optimizar consultas.
4. Validar rendimiento.

---

# Protocolo 7 - Docker

## Objetivo

Crear o mantener entornos de desarrollo.

## Agentes

- Docker Expert
- Reviewer

## Flujo

1. Analizar la infraestructura.
2. Revisar Dockerfile y Compose.
3. Corregir problemas.
4. Validar el funcionamiento.

---

# Protocolo 8 - Mejorar LAB-IA

## Objetivo

Evolucionar el laboratorio.

## Agentes

- Prompt Engineer
- Reviewer

## Flujo

1. Identificar una mejora.
2. Analizar el agente afectado.
3. Proponer cambios.
4. Implementar.
5. Probar.
6. Documentar la mejora.

---

# Regla General

Siempre elegir el protocolo adecuado antes que el agente.

El protocolo define el proceso.

El agente ejecuta la tarea.
